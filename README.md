# ⌨️ Typing Speed Tester Pro

![Python](https://img.shields.io/badge/Python-3.14-blue?logo=python)
![CustomTkinter](https://img.shields.io/badge/GUI-CustomTkinter-green)

A modern desktop Typing Speed Tester built using Python, CustomTkinter, SQLite, and Matplotlib.

---

## ✨ Features

- 🚀 Modern CustomTkinter GUI
- 🎯 Accuracy Calculator
- ⚡ WPM Calculator
- ❌ Error Counter
- 💾 SQLite Database
- 📊 Dashboard
- 📋 Typing History
- 🟢 Easy / 🟡 Medium / 🔴 Hard Modes

---

## 🛠️ Technologies

- Python
- CustomTkinter
- SQLite
- Matplotlib

---

## 🚀 Installation

```bash
git clone https://github.com/jani2496/Typing-Speed-Tester-Pro.git
cd Typing-Speed-Tester-Pro
pip install -r requirements.txt
python main.py
```
